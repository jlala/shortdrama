## 画布指南要点

- **入口与结构：** 可以从短剧 Agent 的资产阶段进入，也可以直接创建空白画布。资产库负责复用，节点承载内容与任务，连线提供后续生成的参考。
- **素材与处理：** 文本、图片、音频、视频均有相应节点；除生成外，还列有宫格切分、抽帧、音频处理、视频局部重拍等工具。部分音频工具标注 Beta。
- **角色与场景：** 同一角色的不同妆造和剧情状态可分形象管理；角色档案可维护主图、补充素材与音色。同一场景可关联多个视角。较长人物设定可放在文本节点中引用。
- **复用与恢复：** 工具箱保存节点组及其连线；应用后仍需检查输入并提交生成。生成历史可定位节点，原节点删除后可将历史结果重新添加到画布。
- **剪辑：** 多轨编辑器编排视频、音频、字幕，支持片段再生成或重拍、配音、字幕识别与样式编辑；视频节点另提供进入剪映编辑的入口。

以上内容依据[画布指南正文](https://bytedance.larkoffice.com/wiki/W2o0wtRvpiqi5sksibkc7Ujuntg)。

## 导演台指南要点

- **推荐顺序：** 先确定静态空间、站位和构图，再添加动作、位移、机位与时间轴。
- **参考输出：** 截图表达构图，录制的视频表达动作与运镜；产物可发送回画布继续引用。
- **参考配合：** 导演台参考需与角色、场景及文本共同使用；构图参考与角色外观参考各自承担不同作用。
- **辅助功能：** 包括图片转可调整白模、手动关节姿势、键盘走位、轨迹应用，以及全景图作为空间背景。

以上内容依据[导演台手册正文](https://bytedance.larkoffice.com/wiki/XenDwLKk8i15VEkZ1HicPKsrnUf)。这些是手册描述的用途，实际生成的一致性与可控程度需要用具体镜头验证。

## 对本项目的应用判断

以下是结合现有工作流提出的使用建议，尚未据此执行生成：

1. 在剧本与分场明确后，建立角色、形象、场景、视角及镜头之间的对应记录，避免把换装当成新角色、把换机位当成新地点。
2. 对多人站位、遮挡、复杂走位及连续空间要求高的镜头，考虑先用导演台排演；普通镜头按实际需要选择参考方式。
3. 在节点引用中分别交代角色外观、场景、构图、动作和声音的来源，不用单一参考替代全部要求。
4. 经具体镜头验证有效的节点组合，再保存为工具箱复用；应用后仍核对输入、选用版本及生成参数。
5. 素材可以进入网页多轨编辑器、剪映或现有本地预演与粗剪流程，按实际能力选择。

可参考的制作顺序：

**剧本与分场 → 角色和场景资产 → 按需进行空间与动作排演 → 分镜与动态镜头 → 配音、字幕与剪辑 → 成片检查。**

## 与现有 CLI 资料的关系

此前的[画布 CLI 官方说明摘要](即梦画布CLI-官方说明摘要.md)侧重命令、引用、积分与任务恢复。本次两份文档侧重短剧工作室的网页制作能力。

项目[安装与查询记录](../.tools/canvas-discovery/README.md)记载 2026-10-28 升级到 CLI 1.2.0，并新增 `director` 等能力。后续于 2026-10-31 完成[网页与 CLI 逐项核验](即梦网页功能与CLI逐项核验-2026-10-31.md)，确认本机版本、只读访问、12 组本地参数检查、三种媒体下载及导演台本地截图／MP4 导出。

核验发现，数字 ID 的短剧工作室项目与 UUID 格式的 CLI 画布尚未建立对应；网页工具箱、角色库、字幕和局部编辑等也没有完整对应接口。导演台视频导出已验证，通用素材时间轴成片导出仍未发现明确入口。具体覆盖与证据边界以逐项报告为准。

本资料属于制作工具参考。通用剧作方法继续使用[短剧剧本创作基本准则 v1.1](短剧剧本创作基本准则-v1.1.md)，具体题材约束在实际项目中另行补充。
