# 短剧剧本创作基本准则

**版本：v1.1**

**修订日期：2026-10-31**

**适用范围：** 真人短剧、竖屏短剧、网络微短剧、漫剧及独立单元、连续剧集式短剧的剧本创作。

**模块定位：** 以元曲创作手法为借鉴的通用剧作基础，重点转化场次经营、人物语言、情景表达及前后照应的方法。具体题材、时代、受众、叙事形式、制作条件与平台要求，在实际项目中另行制定补充约束。

**创作目标：** 人物鲜活、事件有因果、场次有重心、语言有身份、情绪有层次、视听可实现，并保留作品的想象力、风格与余味。

**核心原则：让每一场有所贡献，让每一句对白出于人物，让细节构成生活与意味，让每一篇章有所抵达。**

---

## 第一章：总体创作原则

### 1.1 通过人物行动与关系组织戏剧

短剧通过人物行动、对白、关系、冲突与视听表现展开故事。改编文学作品时，应重新组织适合观看和表演的场景。

创作时遵循以下原则：

1. 尽早让观众接触具体的人、事、关系或异常，建立继续观看的理由。
2. 让人物通过选择、行动与反应显露内心。
3. 以场景为基本叙事单元，让背景信息进入正在发生的故事。
4. 每场戏有可辨认的叙事或感受贡献。
5. 重要冲突应产生后果，影响人物关系、局势或观众认知。
6. 关键进展应有因果依据；巧合可以引发事件，解决核心困境应依靠已建立的条件与人物行动。
7. 在作品约定的表达方式与制作条件下，做到可呈现、可表演、可理解。

冲突是重要的组织手段。关系建立、情感抵达、发现、等待与告别，也可以构成一场戏的中心。

### 1.2 元曲创作手法在短剧中的转化

本准则重点借鉴以下方向，并将其转化为当代短剧的写作方法：

| 借鉴方向 | 在本准则中的运用 |
|---|---|
| 场次经营 | 围绕人物处境组织场面，安排入场、承接、变化与收束 |
| 人物语言 | 让用词、语气、节奏和言外之意体现身份、关系与当下意图 |
| 情景表达 | 通过可见可听的情境、动作、物件与声音承载情感 |
| 前后照应 | 让细节、言语、动作和事件在后文得到呼应，形成整体意味 |

本表是本项目的创作转化框架。文中的七环节场景结构、分集模板和 AI 工作流程，是面向当代短剧的归纳工具，不作为元曲历史创作规条的引文。

形式与语言根据作品需要选择。可以吸收传统表达的节奏与韵味，同时保证观众能够理解、演员能够表演；不机械套用折数、曲牌或固定场次。

### 1.3 区分基础要求、可选手法与项目约束

| 层次 | 内容 | 使用方式 |
|---|---|---|
| 基础要求 | 关键因果有依据、人物行为有来由、已确立设定保持一致、表达可执行 | 定稿与审查时检查；需要改变既定事实时，连同前后依据一起修订 |
| 可选手法 | 七环节场景结构、一景三物、冲突升级、伏笔反转、结尾钩子等 | 根据场景功能选择，可省略、组合或变形 |
| 项目约束 | 题材、时代、受众、风格、媒介、时长、预算及平台要求 | 在具体项目中确定，并与本准则配合使用 |

“必须”只约束条款明确指向的对象。例如，对关键反转要求依据，不等于每场戏都要反转。示例用于说明某种方法，不预设所有作品的情节模式与语言风格。

### 1.4 先发现故事，再选择结构

开放创作可以从人物、关系、画面、情绪、奇想、处境或核心问题出发。

定总纲前，应先明确：这个故事最值得观看的是什么？希望观众经历什么、记住什么？

方向尚未确定时，可以提出若干有实质差异的方案，对比：

- 从谁的视角进入故事。
- 人物最在意什么，最难作出的选择是什么。
- 哪种关系或处境能够持续产生故事。
- 主要观看期待与情绪体验是什么。
- 结局将怎样回应开局，以及留下什么意味。

候选方向可以大胆改变关系、设定与结局。选定方向后，再把它组织成一致的因果链。更换名字、反派或证据，不足以构成不同的创作方向。

已经明确方向的项目可以直接深化；局部改稿与短场景练习按实际需要处理，不强制重做全部开发流程。

## 第二章：开局准则——尽早建立观看理由

### 2.1 让具体情境先发生

开局优先呈现具体的人、事件、关系或异常，避免先集中介绍履历、世界观和复杂规则。

冲突型开局可采用：

**有效事件 → 人物困境 → 利益或立场冲突 → 观众疑问**

例如，将“林晓进入公司后经常受到不公平待遇”转化为：

> 【内景·会议室·日】
>
> 负责人把一份文件扔到林晓面前。
>
> 负责人：“签了。这个项目的责任，你来担。”
>
> 林晓翻到最后一页。签字栏里，已经有了她的名字。
>
> 林晓：“这不是我的字。”
>
> 负责人：“现在是了。”

这种开局适合迅速建立对抗与风险。其他作品也可以通过鲜明人物、关系反差、情绪处境、独特画面或尚未解释的细节建立吸引力，无须一律安排危机或恶人。

### 2.2 建立一个清楚的主要期待

开局应让观众知道自己正在关心什么。例如：

- 人物如何摆脱困境？
- 某个事实为什么与表面不同？
- 这段关系将怎样发展？
- 人物会作出什么选择？
- 眼前的异常将带来什么？

主要期待可以是待解的疑问，也可以是对人物命运、关系或情感的关注。避免同时抛出过多没有重心的问题。

### 2.3 让背景依附于当前叙事

身份、经历、职业与关系，应随当前行动、冲突、情绪或必要叙述逐步呈现。

需要旁白、字幕或简短介绍时，优先提供理解当前故事所必需的信息，控制长度与时机。避免人物无动机地互相讲述双方早已知道的背景。

**执行标准：观众能够理解眼前的情境与人物关切，再逐步获得更深的解释。**

## 第三章：场景准则——一场有重心，场场有贡献

### 3.1 明确本场的核心任务

一场戏可以同时包含行动、对白和信息，但应有清楚的叙事重心。

常见任务包括：争取利益、隐瞒秘密、展开对抗、发现线索、改变关系、呈现威胁、作出决定、建立情感、感受后果，以及形成对环境或人物的独特认识。

允许多种功能相互支撑。多个互不相关的任务争夺中心时，应考虑拆分或调整。

### 3.2 冲突场景的可选结构

重要冲突场景可以参考：

**入场 → 目标 → 阻力 → 加压 → 戏眼 → 转折 → 出场**

| 环节 | 创作作用 |
|---|---|
| 入场 | 确定人物、地点与当前局面 |
| 目标 | 明确人物此刻争取或维护什么 |
| 阻力 | 呈现对手、环境、关系或人物自身带来的阻碍 |
| 加压 | 改变风险、筹码、时间或代价 |
| 戏眼 | 出现具有关键作用的动作、对白或发现 |
| 转折 | 改变人物认知、关系或局势 |
| 出场 | 呈现结果，形成后续承接 |

这是组织冲突的工具，不要求各环节依次出现。重要冲突场景应能说明人物诉求、有效阻力及其后果。

情绪、发现、关系或过渡场景，可以围绕感受的递进、认识的变化或前后承接组织，不必补齐加压、反击和转折。

### 3.3 重要场景应有可感知的戏眼

戏眼是场景中最具戏剧或情感作用的关键点，可以是动作、对白、物件、发现、停顿或沉默。

例如：

> 【内景·客厅·夜】
>
> 妻子：“你说昨晚一直在公司？”
>
> 丈夫：“对。”
>
> 妻子拿出一份手术同意书，翻到丈夫的签名处。
>
> 妻子：“那你怎么签了我妈的手术同意书？”

道具上的签名直接支持质问，形成信息与关系的变化。

戏眼也可以没有揭密或正面对抗：

> 【内景·家门口·晨】
>
> 父亲伸手去提女儿的书包。
>
> 女儿：“今天我自己去。”
>
> 父亲的手停了一下，替她理好卷进书包带的衣领。
>
> 女儿走出门。他留在门内，没有跟上。

场景的重心是父亲通过动作接受关系变化。过渡场景可以只承担清楚的承接作用，不必另造一个突出瞬间。

### 3.4 用场景贡献判断去留

本场结束后，观众应获得有价值的进展或体验，例如：

- 资源、信息、目标或局势改变。
- 人物关系、认识或情绪发生变化。
- 人物的习惯、处境与生活质感得到具体呈现。
- 氛围、期待或主题意味得到建立、深化或回应。
- 前一事件的后果得到感受，后一行动得到承接。

评价一场戏时，应结合相邻场景与整体节奏。若删去后，故事、人物、关系、情绪和氛围均无实质损失，且存在重复，应考虑删除或合并。

## 第四章：人物与对白准则——行为有来由，语言有身份

### 4.1 先建立人物，再分配台词

主要人物应逐步明确以下内容：

1. 他公开追求什么，真正珍惜什么？
2. 他害怕失去什么，受什么经历或认识影响？
3. 他的信念、顾虑与自我认识之间，有什么矛盾？
4. 为了目标，他愿意付出什么，又在哪里犹豫或退让？
5. 面对不同关系，他会显露怎样不同的一面？
6. 哪次选择最能暴露他，选择之后有什么后果？

人物的矛盾应落实为行为。例如，一个人嘴上强调公平，却在涉及亲人时破例；另一个人不善表达，却总记得替人处理琐事。

人物可以成长、退缩、固守或被重新认识。变化方向服从故事，不强制所有人物完成同一种成长弧线。

### 4.2 让说话方式来自人物与关系

对白差异来自年龄、成长环境、职业、身份、教育、性格、当下情绪、权力关系、亲疏程度与说话目的。

主要人物应有可辨识的表达习惯。避免只靠口头禅区分角色，也避免所有人都使用同一种精致、正式、文学化语气。

### 4.3 人物说符合自己身份与处境的话

同样表达对迟到的不满，可以有不同方式：

> 同事：“你可算来了，大家都等你半小时了。”
>
> 主管：“会议九点开始。你看看现在几点？”
>
> 朋友：“怎么着，今天又让我们集体等你？”

这些只是示例。具体语气还应结合人物性格、关系和现场处境，不能按职业机械套用。

### 4.4 重要对白有所贡献

重要对白可以承担要求、拒绝、试探、隐瞒、施压、关系变化、暴露破绽、推动行动、情感交流或信息揭示等作用。

闲谈、重复、玩笑和答非所问，也可以建立亲密、表现回避或显露生活状态。检查其在上下文中的作用，避免反复解释观众已知的信息。

### 4.5 对白允许言外之意

人物可以掩饰、试探、自欺或不知怎样开口。真实意图可通过动作、停顿、回应及上下文呈现。

例如：

> 妻子：“今天回来挺早。”
>
> 丈夫：“公司没什么事。”
>
> 妻子：“那以后都早点回来吧。”
>
> 丈夫：“怎么突然说这个？”
>
> 妻子：“没什么。就是觉得家里挺安静的。”

潜台词应与场面中的情绪与行动相互支持，不必再用旁白逐句解释。

### 4.6 强势台词应有处境支撑

不强制安排反击金句、狠话或情绪宣言。

强势台词的力量可以来自人物处境、关系、情绪积累、实际筹码，也可以来自明知无力仍作出的选择。表达与人物能力之间的距离，应在后续反应或后果中成立。

避免为制造爽点，让人物突然获得不符合设定的口吻、权力或判断力。

### 4.7 对白应适合表演

给动作、停顿、眼神、打断和反应留出空间。根据作品风格使用长短句，不按句子长短判断质量。

重点修改：无动机的背景介绍、角色轮流宣讲观点、重复总结剧情、连续口号，以及任何角色都能互换使用的台词。

**执行标准：观众能从人物怎样说、怎样做、怎样回应中理解他。**

## 第五章：视听表达准则——情境、动作、物件与声音共同承情

### 5.1 关键情绪与事件应可呈现

剧本以画面、声音、人物动作和对白为主要表达形式。关键心理应找到相应的表演、视听或叙述载体。

例如，将“林晓愤怒失望，不愿接受辞退”转化为：

> 林晓看着桌上的辞退通知，拿起笔。
>
> 笔尖停在签字栏上。
>
> 门外传来同事的笑声。
>
> 她放下笔。
>
> 林晓：“我不签。”

简短的状态说明可以帮助理解和表演，重要事件与人物选择仍需在作品中实际发生。

### 5.2 选择有表现力的环境细节

“一景三物”可作为寻找关键视觉元素的练习方法：选择少量能体现处境、关系或氛围的细节，不要求固定数量。

例如办公室中的旧姓名牌、未收拾的纸箱、新负责人占据的位置，可以共同呈现权力变化。

环境也可以通过光线、空间、动作与声音建立，不必每个新场景都列出三件物品。

### 5.3 细节的价值包含生活、情绪与意味

物件和细节可以提供信息、触发行动、暴露秘密、证明身份、制造误会、改变关系、回收伏笔，也可以：

- 显露人物习惯及人与人之间的熟悉程度。
- 建立生活质感、空间气息与时代感。
- 承载难以直接说出的情绪。
- 形成意象、记忆与前后呼应。

重要线索应承担相应作用。一般生活细节不必全部成为证据或伏笔，避免让每件物品都承担揭秘任务。

判断细节时，检查它对整体体验的贡献及占用的篇幅，减少同义堆砌。

### 5.4 通过行动和反应传达情绪

优先观察人物怎样选择、处理物件、靠近或回避他人，以及行动后的反应。

例如：

> 男人把离婚协议推过去。
>
> 女人看了一眼，没接。
>
> 男人：“你还想要什么？”
>
> 女人从抽屉里取出钥匙，放在协议上。
>
> 女人：“房子是你的。孩子跟我。”

动作与对白已经传达态度时，不必再重复解释情绪。

### 5.5 按叙事需要运用声音与旁白

声音可以提供线索、改变空间感、形成期待或延续情绪。沉默也可以成为表达的一部分。

旁白可以组织时间、建立叙述视角、传递主观认识、形成与画面的距离，或完成必要压缩。使用时检查：它是否带来画面之外的价值？是否遮蔽了本应呈现的关键行动？

旁白、对白与画面的比例在具体项目中确定，不预设唯一形式。

## 第六章：冲突准则——诉求明确，阻力有效，选择有代价

### 6.1 冲突来自相互牵制的诉求

设计冲突时明确：

- 人物想获得或维护什么？
- 对手、关系、环境或自身顾虑怎样形成阻碍？
- 冲突各方为什么坚持？各有什么条件与筹码？
- 人物面临怎样的选择，失败或让步会付出什么代价？

冲突可围绕利益、身份、感情、秘密、责任、信念或生存展开，也可以来自两个同样珍惜的目标难以兼得。

双方都可能有合理诉求。合作、照顾和亲密关系中也可能存在冲突，无须一律设置恶人。

### 6.2 冲突应有发展与后果

需要升级时，可参考：

**提出诉求 → 遇到阻力 → 条件变化 → 选择更难 → 人物行动 → 结果改变**

例如：

1. 女儿提出去外地学艺，父亲以需要照顾为由挽留。
2. 她说明已托邻居每日来探望，父亲仍不肯给路费。
3. 她拿出自己攒的钱，父亲发现她早已准备离开。
4. 父亲说：“出了这个门，往后别回来。”
5. 女儿放下家门钥匙，走到门边，又折回把父亲的药分进药盒。
6. 父亲看着药盒，没有再拦。她拿走了行李，钥匙仍留在桌上。

这里的加压来自双方诉求与行动，结尾留下选择的代价。冲突也可以通过妥协、逃避、失败、认识改变或暂时共处发展，不要求每次都完成反击与获胜。

避免只靠提高音量、增加辱骂或连续加入新恶人维持强度。

### 6.3 关键解困与反击应有依据

人物使用的能力、资源与信息，应与已建立的条件相容。决定性证据、身份、援助或能力需要足够依据。

新信息可以出乎观众意料，但不应随意推翻已经明确的事实。人物可以误判或失败，其后果同样应成立。

### 6.4 情绪应有过程与回应

情绪可以通过试探、期待、压制、误判、忍耐、损失、理解与选择逐步形成。

强烈爆发需要相应积累；克制、缓慢变化和未能说出口，也可以构成情绪中心。关键情绪出现后，给人物反应及其后果留出空间。

---

## 第七章：伏笔与照应准则——前有来由，后有回应

### 7.1 根据后续作用设计伏笔

重要伏笔可以参考：

**首次出现 → 再次触发 → 获得新意义 → 回收或回应**

是否需要反转、解释或推动下一次行动，由故事决定，不要求每个伏笔走完同一套步骤。

例如，父亲每月向陌生账户转账，先被误解为隐瞒私情，后被发现是在补偿旧日事故中的幸存者。同一事实因新信息而改变意义；后续是否还有隐情，应由整体结构决定。

### 7.2 使用可识别的载体

载体可以是物件、照片、文件、动作、习惯、话语、异常细节或尚未解释的关系。

识别程度与出现次数服从观看需要。避免重复提醒到直接泄露答案，也避免关键信息弱到无法支持后文。

### 7.3 回收应与前文相容

按适用情况检查：

1. 是否与已经建立的事实一致？
2. 是否具有足够的前置依据？
3. 是否改变对旧事件的理解，或回应人物与情感？
4. 是否对当前篇章产生有价值的作用？
5. 是否符合人物行为逻辑？

避免为反转篡改明确事实。视角受限、人物撒谎或误认，应在叙述方式中能够成立。

### 7.4 区分伏笔、悬念、反转与照应

- **伏笔：** 为后续事件提前建立依据。
- **悬念：** 让观众关心尚未解决的问题。
- **反转：** 通过新信息或行动改变原有判断或局势。
- **照应：** 前后的细节、动作、话语或情境形成联系，可以深化情感与意味。

照应可以不揭示秘密，意象也不必都成为待解释的谜题。四者根据作品需要配合使用。

---

## 第八章：节奏准则——持续投入，张弛有度

### 8.1 保持有价值的推进与体验

场景可以推动剧情、关系、情绪、信息、人物认识、氛围或观众期待。

节奏紧凑来自无效内容少、重心清楚、变化可感，不要求固定秒数出现刺激或反转。

连续数场贡献相近时，应检查是否原地重复。氛围与情绪场景同样需要控制篇幅及相邻关系。

### 8.2 让强弱、快慢与疏密形成节奏

冲突段落可参考：

**建立期待 → 制造阻碍 → 加强压力 → 情绪回应 → 结果或新问题**

其他段落可以通过接近与疏离、认识与误解、等待与抵达组织节奏。

缓冲段落可用于感受后果、建立关系、理解人物和完成告别。根据整体需要安排，不以持续加压作为唯一标准。

### 8.3 根据篇章位置安排分集

每集应有可辨认的核心事件或情绪中心，并带来实质进展、感受深化或阶段性完成。

连续叙事剧集可以在自然收束处保留后续期待。独立单元与终集，应重视自身的完成度。

不强制每集设置高潮、身份反转或极端危机。前集建立的承诺应得到进展或回应，避免只新增问题、不推进已有问题。

### 8.4 钩子应来自当前故事

钩子可以来自秘密、决定、新信息、行动后果、关系变化或尚未完成的情感期待。

避免加入与当前故事无关的事件，或靠中断一句话、拖延已有答案制造空悬念。选择停顿位置时，同时考虑本集已经给予观众什么。

### 8.5 时长服从表达需要与项目条件

避免为填满时长延长争吵，也避免为压缩时长删去必要的反应、因果与情绪积累。

具体时长和节奏规格在项目中确定，并通过朗读、预演或实际媒体检查校正。

### 8.6 结尾要回应主要承诺

独立故事、单元结束与整剧结尾，应回应其主要行动、关系或情感期待，呈现关键选择的后果。

可以保留开放问题、未知与余味，但应区分有意留白和遗漏必要交代。留白范围及结尾气质由具体作品确定。

---

## 第九章：语言准则——自然、准确、符合人物与作品

### 9.1 语言服务于人物与表演

优先使用符合人物身份、所处时代与作品风格的自然语言。

文学性可以来自准确、节奏、意象和言外之意。复杂修辞、感叹号、反问与狠话的数量，不代表情绪强度。

本准则不预设所有题材都采用现代口语，也不要求统一古雅。具体语言尺度在项目中确定。

### 9.2 区分不同表达的职责

| 表达 | 要求 |
|---|---|
| 场景说明 | 帮助理解时间、空间与情境，关键内容可实现 |
| 动作描述 | 具体、准确，给表演与反应留出空间 |
| 人物对白 | 来自身份、关系、说话意图与当下情绪 |
| 旁白或独白 | 具有叙述视角与独立作用，避免无效复述 |
| 情绪高潮 | 强度与人物处境、积累及作品风格相容 |

### 9.3 检查模板化表达及其成因

重点检查以下情况是否削弱了作品：

- 人物无缘由地总结道理或喊口号。
- 所有人用同一种语气，重要台词可以任意互换。
- 连续场景重复同一套施压、反击与揭密。
- 抽象情绪词替代关键行动与反应。
- 对白反复介绍观众已知内容。
- 独白与旁白掩盖了场景没有实际发生的内容。
- 为金句或反转牺牲人物逻辑。

人物有依据的总结、刻意重复或风格化表达，可以保留。判断其在上下文中的作用，避免只按词语与句式机械删除。

### 9.4 允许语言具有真实的节奏

根据人物与情境，允许完整句、长短句组合、打断、迟疑、沉默、重复与说到一半改口。

**语言自然度、表演价值与作品风格，优先于形式整齐。**

## 第十章：分层开发与剧本格式

### 10.1 分层推进，允许往返

完整开发可参考：

**方向探索 → 人物与关系开发 → 故事总纲 → 分集大纲 → 分场大纲 → 剧本正文 → 审查修改**

| 层级 | 核心内容 |
|---|---|
| 方向探索 | 观看价值、创作视角、候选方向与结尾意味 |
| 人物与关系 | 欲望、顾虑、信念、矛盾、关系及关键选择 |
| 故事总纲 | 核心处境、主要事件、因果链、人物变化与结局 |
| 分集大纲 | 每集核心事件或情绪、进展、结果、收束与承接 |
| 分场大纲 | 场景功能、人物行动或感受、关键时刻、结果与承接 |
| 剧本正文 | 场景、动作、对白、必要声音与叙述提示 |
| 审查修改 | 创作意图、因果、人物、节奏、语言与视听可执行性 |

各层可以互相修正。用户只要求某一环节时，利用已有资料完成该环节，缺少关键依据时再补足必要开发。

### 10.2 分集大纲模板

按篇章位置填写；不适用的项目可省略或标明，不为填满栏目虚构冲突与钩子。

**集数及篇章位置：**

**本集核心事件或情绪中心：**

**主要人物当前诉求与处境：**

**主要冲突或推进过程：**

**人物关系、认识或情绪的变化：**

**重要信息、细节或照应：**

**关键时刻：**

**本集结果与观众获得的回应：**

**收束方式与后续期待（如适用）：**

**与整体故事的关系：**

### 10.3 分场大纲模板

通用栏目：

**场次编号、地点与时间：**

**出场人物：**

**本场核心任务或感受贡献：**

**人物当下意图、处境或情绪：**

**主要行动、交流或感受过程：**

**关键时刻／戏眼（如适用）：**

**本场结果、变化或体验的深化：**

**前后承接：**

按需要补充：

**阻力、风险与代价：**

**冲突发展及转折：**

**关键视听细节、道具与伏笔：**

**预计时长：**

### 10.4 剧本正文基础格式

**第X集**

**场X-X 内／外景·地点·日／夜**

出场人物：人物A、人物B

【动作描述】

人物A：对白。

【人物动作或反应】

人物B：对白。

【关键行动、情绪或局势变化】

根据制作需要，增加音效、旁白、屏幕文字、必要镜头提示与特殊视觉效果。镜头提示以帮助理解关键表达为度，具体分镜另行展开。

## 第十一章：AI 辅助创作准则

### 11.1 区分探索、建构与成稿

完整项目应逐步明确方向、人物与关系、主要事件和结局，再组织分集、分场与正文。

探索阶段允许提出不同视角、关系、设定与结局，并说明各自的观看价值及需要解决的问题。候选内容应与已经确定的版本区分，避免把尝试自动写成事实。

建构阶段检查选择的方向是否能形成有依据的事件与关系发展。可以调整结构，也应同步修改受影响的铺垫与后文。

成稿阶段运用具体行动、对白与视听表达，保持人物、设定、语气与前后事实一致。局部任务可以直接进入相应环节。

### 11.2 先判断场景功能，再选择检查问题

所有场景先明确：

1. 谁在什么情境中？人物当下在意什么？
2. 本场希望观众理解、感受或期待什么？
3. 通过什么行动、交流或视听细节实现？
4. 本场对前后故事有什么贡献与承接？

重要冲突场景再明确：

1. 人物具体争取或维护什么？
2. 谁或什么构成有效阻力？
3. 条件、风险或代价怎样变化？
4. 什么选择或关键时刻影响场面走向？
5. 冲突产生什么结果与后果？

情绪、发现、关系或过渡场景按自身功能检查，不为通过检查而强加对抗、反击与反转。必要依据不清楚时，先补足场纲；检查过程不必全部写入正文。

### 11.3 既定版本中的重大变化需要前后依据

在已经确定的故事中，新增关键身份、重大身世、决定性证据、人物、能力或行为转向时，检查它是否与现有事实、动机和因果链相容。

方向探索或结构改稿可以提出重大变化，并说明需要改动的铺垫与后续。避免在局部扩写时悄然加入能够解决一切的新条件。

用户已有的明确决定与已确认设定应持续沿用；常规写作细节在既有范围内完成，不逐项请求确认。

### 11.4 改稿先处理表达与戏剧问题

修改顺序可参考：

**创作意图 → 因果逻辑 → 人物动机与选择 → 场景功能与关系 → 冲突有效性 → 情绪节奏 → 对白与视听表达 → 语言润色**

按实际问题确定重点。修改时保留原稿有价值的人物细节、独特气息与表达尝试，不为统一格式抹平差异。

避免只靠删除形容词、缩短句子或添加流行台词完成“去 AI 味”。

## 第十二章：质量审查与验收准则

审查用于发现问题与决定修改重点。以下项目均以“符合”为勾选依据；只检查适用项，不适用时标记原因，不要求所有场景具备同一种结构。

### 12.1 场景审查

- [ ] 本场有可辨认的叙事重心或感受贡献。
- [ ] 行动、对白与视听细节能够支持这一贡献。
- [ ] 重要冲突场景有明确诉求、有效阻力及后果。
- [ ] 重要场景有可感知的关键时刻，过渡场景承接清楚。
- [ ] 与相邻场景比较，内容具有必要的增量、深化或节奏作用。
- [ ] 已减少无效对白与同义重复，同时保留必要的情绪和生活细节。
- [ ] 关键内容能在约定的表达形式中实现。

### 12.2 人物审查

- [ ] 主要人物的欲望、顾虑与重要关系清楚。
- [ ] 行为及关键选择符合人物的动机、认知与所处条件。
- [ ] 矛盾、改变或反常行为具有足够依据。
- [ ] 对白与人物身份、关系和当下情绪相容。
- [ ] 人物的表达与行为具有可辨识性，而非只靠口头禅。
- [ ] 人物选择的后果得到体现，配角也有与自身处境相关的诉求。

### 12.3 剧情与篇章审查

- [ ] 核心事件之间有成立的因果联系。
- [ ] 关键解困、反转与新设定具有足够依据。
- [ ] 前后明确事实一致，视角受限与人物误认能够成立。
- [ ] 已设置的重要伏笔有合理回应，照应不必全部变成揭密。
- [ ] 核心困境的解决依靠已建立的条件与人物行动。
- [ ] 连续篇章对已有期待有进展，收束与后续承接自然。
- [ ] 独立单元及终集回应主要承诺，留白与遗漏能够区分。

### 12.4 视听与制作审查

- [ ] 关键事件与情绪有清楚的视听或表演载体。
- [ ] 动作、道具、声音与必要效果描述明确。
- [ ] 旁白与对白具有相应作用，给表演和反应留有空间。
- [ ] 场景及复杂动作的设计与实际项目的制作条件相容。
- [ ] 已减少没有表达价值的复杂场面与重复细节。
- [ ] 预计时长与内容密度相容；进入制作时能够通过朗读或预演校正。

### 12.5 风格与模板化审查

- [ ] 场景的组织方式服从其功能，避免连续复制同一种冲突或反转。
- [ ] 重要台词来自具体人物与关系，避免任意互换。
- [ ] 解释性内容控制得当，关键行动在作品中实际发生。
- [ ] 金句、总结、修辞与重复有情境依据。
- [ ] 想象、生活质感、情绪层次与余味得到适当保留。
- [ ] 修改后的作品仍有明确的观看价值与自身表达特点。

基础要求中的重大因果、动机或设定问题应优先修正。是否使用某种公式、是否设置反转或是否解释某个意象，根据表达意图判断，不作为统一淘汰条件。

## 第十三章：最终执行原则

1. **先发现值得讲的内容，再选择结构。** 允许多种起点与候选方向，避免过早锁死。
2. **人物有来由，选择有后果。** 欲望、顾虑、关系与认知共同影响行动。
3. **一场有重心，场场有贡献。** 贡献可以来自事件、关系、情绪、认识、氛围或承接。
4. **语言有身份，话语有情境。** 对白与人物、关系、时代及作品风格相容。
5. **冲突有诉求，发展有代价。** 需要对抗的场景应有有效阻力，不强制所有场景争斗。
6. **关键解困有依据，重要反转守事实。** 新意与因果可信共同成立。
7. **情景共同承情，细节构成生活与意味。** 保留有价值的动作、声音、物件、沉默与余味。
8. **前后有照应，节奏有张弛。** 让篇章形成联系，给变化与后果留出感受空间。
9. **篇章有所抵达，承诺得到回应。** 连续叙事安排承接，独立单元与结尾重视完成度。
10. **方法随表达选择，定稿接受检查。** 可选工具按需运用，人物、因果与视听实现保持可信。

### 常用结构参考

**冲突场景可参考：**

入场 → 目标 → 阻力 → 加压 → 戏眼 → 转折 → 出场

**其他场景按功能组织：**

围绕人物关系、发现、感受或承接展开，检查是否形成有价值的进展或体验。

**连续篇章可参考：**

建立期待 → 展开行动与关系 → 形成变化或感受深化 → 阶段回应 → 收束与承接

**完整开发可参考：**

方向探索 → 人物与关系开发 → 故事总纲 → 分集大纲 → 分场大纲 → 剧本正文 → 审查修改

**最终标准：**

**人物可信，因果成立，场次有贡献，语言有身份，情感有过程，篇章有回应，表达有自身特点。**

本准则作为通用基础使用。具体题材与制作项目另行补充约束，说明哪些方法适用、需要怎样调整，并与人物逻辑、关键因果及视听可执行性保持一致。
